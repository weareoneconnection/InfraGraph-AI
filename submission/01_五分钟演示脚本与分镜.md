# InfraGraph AI 五分钟演示脚本与分镜

赛道：交通知识资产构建与应用。目标时长 4 分 30 秒，不超过 5 分钟；旁白按每秒约 4 个汉字核算。

主线：中英文工程资料入库 → 自动抽取实体与关系、跨语言对齐、句子级出处 → 中文问英文资料 → 主张核验识别“相反的说法” → 低置信度人工复核 → 发布带哈希的知识版本 → 智能体通过 MCP 调用。

## 录制准备

- 启动：`./run.sh`，浏览器打开 `http://127.0.0.1:8102`；录制前删除 `data/infragraph.db`。
- 画面 1920×1080，浏览器缩放 90%；分段录制、剪辑合成。
- 只使用 `data/corpus.jsonl` 中的合成资料。

## 分镜

| 时间 | 段落 | 画面与操作 | 旁白 |
| --- | --- | --- | --- |
| 0:00–0:08 | 片头 | 片头卡：作品名称、中国港湾工程有限责任公司、交通知识资产构建与应用赛道 | （配乐） |
| 0:08–0:35 | 痛点 | 并排展示一份中文不符合项报告和一份英文检验记录（合成） | 海外项目的工程资料中英文混写，同一个墩、同一个病害有好几种写法。知识藏在句子里，查不到、对不上，更没法证明某个说法有没有依据。 |
| 0:35–1:15 | 知识生产 | “知识生产”页粘贴“P52墩柱拆模后发现裂缝，已开具NCR-0042。裂缝须采用环氧注浆修补，并按照GB 50204-2015进行复检。”抽取入库 → 实体与关系列表，每条带引文；再点“载入演示语料” | 一份资料进来，系统分句、识别构件、病害、措施、标准和条款编号，按本体建立关系。注意这条：标准只归属同一分句里的“复检”，不会错挂到“环氧注浆”。每条关系都保留原文和字符位置。 |
| 1:15–1:50 | 图谱与跨语言 | “图谱浏览”页，点 P52 节点：别名“P52墩柱 / Pier P52”，“中英文已对齐”，关系来自中文和英文两份资料 | 中文的“P52墩柱”和英文的“Pier P52”是同一个实体，“裂缝”和“crack”也是同一个。图谱里每条边都能点开看到原文出处。 |
| 1:50–2:20 | 混合检索 | “混合检索”页输入“crack on Pier P52 repair method” → 识别实体并命中中文不符合项报告 | 用英文问，命中的是中文报告。检索不只看字面，还看实体：问题里提到了 P52 和裂缝，提到同一实体的句子就会被找出来。 |
| 2:20–3:10 | 主张核验 | “主张核验”页：①“P52 pier crack requires no corrective action and can be closed immediately”→ 相互矛盾，依据“裂缝须采用环氧注浆修补”；②“工期延长须在事件发生后7天内通知”→ 相互矛盾，原文 28 天；③“TUN-01 tunnel ventilation fans require monthly maintenance”→ 证据不足 | 智能体最需要的不是更会说话，而是知道一句话对不对。原文要求修补，这条说法却说不需要，判为相互矛盾；原文是 28 天，这里写 7 天，也是矛盾；知识库里根本没有的内容，判为证据不足。 |
| 3:10–3:50 | 复核与发布 | “知识生产”粘贴“巡检发现P70和P71墩存在裂缝和剥落。”→“复核与发布”页显示 4 条待复核、闸门红叉；尝试发布被阻断；确认 P70、驳回 P71；发布 2026.10-r1 → 清单哈希、差异 | 一句话里有两个墩、两种病害，系统无法确定对应关系，就交给人复核；复核没清空，不能发布。发布前还要逐条核对引文与原文一致，最后冻结清单并计算哈希，和上一版自动比较差异。 |
| 3:50–4:15 | 指标与 MCP | 终端运行 `python evals/run_eval.py` 显示 PASSED；展示 MCP 工具列表 | 在 50 条人工标注关系上，F1 为 0.98；检索前三命中率 100%；18 条主张的判定和依据全部正确。智能体可以通过 MCP 检索和核验，但入库、复核和发布由知识管理员完成。 |
| 4:15–4:30 | 片尾 | 片尾卡 | 让每一条工程知识都有出处、有版本、可核验。InfraGraph AI。 |

## 故障预案

| 风险 | 处理 |
| --- | --- |
| 图谱布局拥挤 | 点击实体后用“只看邻域” |
| 发布提示版本已存在 | 换一个版本号 |
| 需要展示大模型抽取 | 本版本默认规则抽取，配置模型后才启用，不要宣称已用大模型 |

## 录制前检查

- 画面中无真实资料、项目名称或密钥；标准编号仅作为标识符。
- 成片不超过 5 分钟，另一台设备完整播放检查声音字幕。
