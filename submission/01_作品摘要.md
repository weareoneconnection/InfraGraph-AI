# InfraGraph AI 作品摘要

**作品名称：InfraGraph AI——交通基础设施知识资产工厂与工程知识图谱平台**

定位：面向交通行业工程资料分散、版本复杂、知识隐性、AI难以追溯来源的问题，建立从原始资料接入到知识资产发布的生产流水线，将文档转为带来源、版本、哈希、司法辖区、生命周期和专业领域元数据的 Knowledge Asset，并建立可计算的工程关系图谱与证据图谱。

核心链路：Ingest → Parse → Extract → Normalize → Entity Resolution → Ontology Mapping → Relation Build → Provenance Gate → Knowledge Release → Search/Claim Verification。

当前包提供独立 Web/API、工程 Ontology、SQLite FTS5 检索、Graph Explorer、Claim Verification 和带 SHA-256 的知识发布快照。默认数据均为合成示例。
